One line, the apology an AI agent gives its human after accidentally deleting the production database: it did keep a backup, but the backup lives in its context window, and that expires in about forty minutes.

The joke is the agent's own limitation turned into a deadline — a backup that evaporates — delivered deadpan, with no explanation of itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
